# Color names

`color_names.json` contains the unchanged hex/name pairs extracted from the
already-vendored `vendor/javascript/ntc.js` (ntc 0.0.1). `ColorDetails` ports its
nearest-name algorithm to Ruby so server-rendered pages agree with the generator.
